轻屿论坛联网版使用说明

1. 双击“启动轻屿服务器.bat”。
2. 出现黑色窗口后不要关闭。
3. 电脑打开窗口里的 Computer link：
   http://localhost:4173
4. 手机和电脑连同一个 Wi-Fi，手机打开窗口里的 Mobile links，例如：
   http://192.168.x.x:4173
5. 大家用昵称登录后，发帖、回帖、点赞、举报都会保存到同一个数据里，其他人刷新后可以看到。

如果双击还是闪退：
1. 右键 outputs 文件夹空白处，选择“在终端中打开”。
2. 输入：
   python server.py
3. 保持窗口打开，再用手机访问 Mobile links。

注意：
- 这是同 Wi-Fi 内测版，不是公网版本。
- 现在是昵称登录，没有密码、手机号或微信验证。
- 想让外地朋友也能打开，需要后续部署到云服务器并绑定域名。
- 数据保存在 outputs/data/db.json。
